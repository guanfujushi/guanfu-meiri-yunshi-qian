## 这是什么

一张**传统历法的每日卡片**。

它做的是老黄历右上角那一栏的事：今天是什么干支日、哪个神值日、传统上宜做什么忌做什么。我用脚本把这些算出来，写成一张 30 秒能读完的卡。

它**不是**预测工具，**不判**吉凶，**不针对**任何个人。

## 关于精度（如实说明）

年柱以立春为界、月建以节气为界，两者都由**太阳视黄经实时计算**，不查表、不硬编码。

中等精度天文公式有约 **0.01° 的固有误差**，换算到节气时刻约 **±6 分钟**。

影响范围：

- 只有**恰好落在节气交接当天**的日期，年柱或月建可能有半日偏差；
- 一年 24 个节气，受影响的日期全年不超过 24 天，且多数偏差不足以改变结果；
- **日柱不受影响**——日柱按日期直接推算，与节气无关，永远准。

需要精确核对时，请以权威万年历为准。这条限制写在明面上，比藏在代码里好。

## 常见问题

**Q：为什么同一张卡人人一样？**

因为日签讲的是「这一天」，不是「你」。它没有输入任何个人信息，也不可能针对个人。想知道跟自己相关的事，那是另一套工具的事。

**Q：宜忌每天都不一样，是随机的吗？**

不是。建除十二神按「月建起建、依次顺行」排出，日支落在第几位就是哪一位，完全确定。同一天跑一百遍，结果一样。

**Q：破日、危日看着不吉利，是不是不能做事？**

那是古人的说法，不是你的判决书。传统上「破日」宜拆旧不宜立新——它说的是一天的调子，不是你的运气。

**Q：能算我个人的运势吗？**

不能。本工具只看日期，不看人。任何"输入生日出个人运势"的功能都不在本包范围内。
